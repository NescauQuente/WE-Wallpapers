# WE-Wallpapers

Animated wallpapers for Wallpaper Engine (**Web** type) that also run in a browser and on CasaOS.

| Folder | What it is |
|---|---|
| `star-wallpaper/` | **Starry Orbit**: a starfield with a black hole, nebulae, hyperspace and rare events |
| `plexus-wallpaper/` | **Neural Plexus**: a living 3D network with signals, formations, an audio visualizer and a particle clock |

On CasaOS they run through **Live Wallpapers**, a mod that provides the Wallpaper Engine web API; it lives in its own repository, [NescauQuente/CasaMODs](https://github.com/NescauQuente/CasaMODs) (`casaos-live-wallpapers/`).

Each folder has its own README (and a `CLAUDE.md` with the working rules for that project).
